#+DATE: <2026-07-02>
#+FILETAGS: :emacs:security:

I've been using Apple's Passwords.app, but [[https://www.passwordstore.org/][password-store]] (pass) seemed very cool, and since I already did the heavy-lifting of setting up the YubiKey, I decided to migrate.

Another reason that convinced me: [[https://www.gnu.org/software/emacs/manual/html_mono/auth.html#The-Unix-password-store][Emacs supports pass as an auth-source natively]]! Here is a sample:

#+BEGIN_SRC emacs-lisp
  (auth-source-pass-enable)

  (auth-source-pass-get 'secret "foo/bar")
#+END_SRC

You can also use [[https://git.zx2c4.com/password-store/tree/contrib/emacs/password-store.el][password-store.el]] to interact with pass via Emacs.
